## 구성과 번호
- 강마다: 개념 설명 + '개념 익히기' 쌍둥이 문제 `1-1`/`1-2`(왼/오른쪽 단, 가끔 `1-3`) → **num = n×10+k, label = "n-k"** (중3_체크수학과 같은 방식)
  / '개념 체크' 1, 2, 3… / '개념 완성' 01, 02… / 단원 테스트 01~.
- 개념 설명 상자 안의 예시(풀이가 붙은 것)는 번호 모양이 없어서 안 들어감.

## 방법 (도구로 번호를 못 읽어서 우회)
- Windows OCR 이 이 교재의 번호(청록·남색 굵은 숫자 `1-1`, `01`, `1`)를 거의 못 읽음(probe --ocr 결과 대부분 누락).
  그래서 **번호 글자 모양(높이 10.5~17pt 덩어리, 단 왼쪽 끝)을 이미지에서 찾고, 번호 조각만 잘라 한국어 OCR 로 읽어**
  쪽 안 순서(단 우선/줄 교차)와 맞춰 번호를 매긴 뒤, 전부 `manual_labels` 로 넣음 (layout.json 의 manual_labels 791개).
  `label_regex` 는 아무것도 안 잡히게(`^(?!)…`) 하고 `rescue:false`, `groups:false`, `drop_outliers:false`.
- 단: 홀수 쪽 x 46~296.5 / 303~552, 짝수 쪽 x 40~291 / 297.5~546 (가운데 선 홀 300, 짝 294.5 를 피함). body [58, 776].
