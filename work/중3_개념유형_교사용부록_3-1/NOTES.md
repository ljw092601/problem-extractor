## 수동 보정 (fix_bbox.py — 코드 수정 아님, core.extract 함수만 읽어 씀)
다시 뽑을 때: `python book_tool.py extract <pdf> layout.json --out D --no-sheets` → `python fix_bbox.py <pdf> D/problems.json <slug폴더>`
1. 기초 강화 문제: 아랫변을 다음 번호/유형 띠 바로 위까지 큰 여백으로 다시 잡음, 윗변이 유형 띠를 물면 띠 아래로.
2. 14쪽 오른쪽 맨 위 (5)~(10) → 14쪽 왼쪽 2번의 continued 조각.
3. 서술형 '선택형'(N-1, N-2, N-3 중 하나 골라 풂, 88·91·93·96·99·102쪽) → '선택형' 띠부터 풀이 과정 도장까지 **한 문제**(num=N).
   (번호가 'N' + '-1' 로 쪼개져 있어 93쪽은 7번이 3번 잡혔던 것을 하나로 대체, 나머지는 번호 영역 밖이라 안 잡혔던 것을 추가)
4. 번호 위 '[주관식]'·'[서술형]' 표시를 윗변에 포함, 1~2회 쪽의 '1회/2회' 색 띠를 물면 띠 아래로.
- merge_continued(읽기 전용) 확인: 748 → 747 (continued 1개만 합쳐짐, 서로 다른 문제 합침 없음 → num_end 막음 불필요).
