## 단원 (units.json, 26개)
책이 '영역별'(계산력 → 소단원 확인 → 중단원 수준별 → 수행 과제 → 대단원 TEST) 순이라 같은 중단원이 여러 번 나옴.
group = 영역 이름, title = 중단원(Ⅰ-1 …) 으로 나눔 (대단원 TEST 는 대단원 단위, 수행 과제는 하나).

## 남은 문제점
- 수행 과제(82–88쪽): 지문 시작 y 를 직접 지정(manual_groups, y=195/200). 한 쪽 전체가 한 문제라 영역이 큼(높이 ~440pt). 소문항 01~03 을 따로 쓰려면 지문이 빠지므로 묶음으로 둠.
- 대단원 TEST 서술형 19번 등의 공통 지시문("풀이 과정을 자세히 쓰시오")은 영역에 없음.
- 번호 겹침 경고(중복 번호)는 수행 과제 묶음이 모두 1번에서 시작해서 생긴 것 — 정상.
- 다음 단/쪽으로 이어지는 문제는 보지 못함.
