## 번호를 어떻게 잡았나 (쎈B 공통수학1 과 같은 방식)
- 색 2자리 번호는 OCR 이 자주 놓쳐서, 각 문제 오른쪽 위의 쎈 본책 참조번호(`쎈 0053`)를 OCR 로 찾아 **문제 위치 기준**으로 삼음
  (참조번호 값이 쪽 순서대로 증가하는지 최장 증가 수열로 확인해 가짜 숫자 제거).
- 참조번호를 못 읽은 문제는 OCR 2자리 번호가 순서에 맞을 때만 사용. 개념 정리 쪽 다음에서 번호 01 로 다시 셈.
- 전 문제를 **`manual_labels`(250개)** 로 넣음. `label_regex` 는 일부러 안 맞는 `^(ZZZZ)$`, rescue/groups/drop_outliers 끔.
- 스크래치 스크립트로 만든 manual_labels 를 layout.json 에 그대로 적음(정규식 역슬래시 없음). 다시 extract 해도 결과 같음.
- OCR 로 읽힌 2자리 번호와 매긴 번호가 어긋난 곳 없음. 수동 추가 없음.
