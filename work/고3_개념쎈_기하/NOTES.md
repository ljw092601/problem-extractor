## 구성과 처리
- 쪽 구성: 개념 설명(Check 예제는 풀이 붙음 → 뺌) / **대표유형 NNN (풀이 붙음 → 뺌)** / **유제 NNN-❶, NNN-❷ (넣음)** / 중단원 끝 **연습 문제 01~NN (넣음)**
- 번호 모양이 둘이라 레이아웃 2개로 따로 추출 후 합침 (베이직쎈처럼):
  - `layout.json` : 유제. 번호 `NNN-❶` (OCR 은 `003-0`) → `label_regex` `^(\d{3})\s*[-—–~_]` (대시 필수라 대표유형 `003` 은 안 잡힘).
    연습 문제 쪽은 `skip_pages`.
  - `layout_연습문제.json` : 연습 문제 쪽만 (37-41, 69-72, 94-97, 114-117, 144-147, 176-180, 214-218). 번호 `01` 큰 글씨, x≈66~75.
    '서술형'·'STEP' 표시를 넣으려고 `top_pad` 30.
  - `problems.json` = 두 결과를 쪽·y 순으로 합친 것, `report.txt` 도 둘을 이어 붙임.
- **유제 번호(num)는 대표유형 번호** → 같은 쪽에 같은 번호가 2개(가끔 1개·3개) 있음 (❶❷ 구분은 num 에 없음, label 에는 있음). `drop_outliers: false`.
  대표유형 70개, 유제 1개뿐인 것 15개, 3개인 것 3개(36, 57, 61) → 70×2−15+3 = 128 로 개수 맞음 (probe 로 확인).
- 연습 문제 번호는 중단원마다 01부터 다시 시작.
- 홀짝 쪽 좌우 밀림 있음 (짝수 쪽 +6pt) → `columns_even`.
