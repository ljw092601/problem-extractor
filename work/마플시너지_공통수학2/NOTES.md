- 1~386쪽 스캔본(595x842), 387~560쪽 '내신연계문제' 는 글자 PDF(638x842, 다른 판형)지만 번호 글꼴 조각이 깨져서(`007`→`700`) 전부 `"source": "ocr"` 로 통일.

  각 구간 번호 빠짐·중복 없음 (본문 0001~1895, 모의평가 회차마다 01~25, 내신연계 001~918).
- 단원: 32개 (`units.json`) = 본문 중단원 12 + 모의평가 회차 8 + 내신연계 중단원 12

```
python work\마플시너지_공통수학2\extract_minh.py extract <pdf> work\마플시너지_공통수학2\layout_main.json   --out D1

python work\마플시너지_공통수학2\extract_minh.py extract <pdf> work\마플시너지_공통수학2\layout_mock.json   --out D3
python work\마플시너지_공통수학2\extract_minh.py extract <pdf> work\마플시너지_공통수학2\layout_linked.json --out D4
python work\마플시너지_공통수학2\merge.py work\마플시너지_공통수학2\problems.json D1\problems.json D2\problems.json D3\problems.json D4\problems.json
```
- `extract_minh.py`: core 는 고치지 않고 book_tool 을 불러 OCR 번호 후보에 `label_min_h`(12pt) 높이 거르기만 추가.
  보기 '①12'가 '012'로, 쪽 번호 등이 번호로 오인되는 것을 막음(특히 모의평가 2자리 번호에 필수).
- 본문은 `"groups": false` — 231쪽에서 OCR 이 '[1단계]…' 류를 묶음 머리글로 오인해 6문제를 하나로 묶었기 때문. 이 책엔 실제 묶음 문제 없음.
- sheets 는 구간별로 scratch 에서 확인했고 work 폴더엔 넣지 않음(필요하면 위 명령으로 재생성).
