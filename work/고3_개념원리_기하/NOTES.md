# 고3_개념원리_기하

- 원본: `고3/개념원리 기하.pdf` (로컬 사본 `work\_src\고3\개념원리 기하.pdf`)
- **같은 내용 사본**: `고3/개념원리 기하 (1).pdf` — 파일 md5 동일, 오케스트레이터가 같은 좌표로 함께 등록
- 텍스트 PDF (source: text), 232쪽, 533x729pt
- 최종 문제 수: **462개** (묶음 없음, 이어진 조각 없음)
- 확신도: **상**

## 방법
편집이 `고3_개념원리_미적분` 과 같아서 그 스크립트(gen_manual.py, merge_parts.py)를 가져와 씀.
- 문제 번호를 글꼴·크기로 골라 manual_labels 로 넣음 (label_regex 는 안 맞게 막아 둠):
  - layout_a: UniversLTStd-BoldCn 15.6 (x 54/60) = 개념원리 익히기·연습문제·실력 UP → 272개
    (+ 191쪽 연습문제 173번은 글자 크기가 14.0 이라 x<80 조건으로 A 에 넣음)
  - layout_b: UniversLTStd-BoldCn 14.0 (x 102/108, 특강 122/128) = 필수예제 아래 확인체크 → 190개
  - **필수예제**(Helvetica-Bold 14.2, 풀이 붙음)는 넣지 않음
- 번호 확인: 익히기+확인체크 1~250, 연습문제+실력UP 1~212 — 빠짐·중복 없음 (250+212=462)
- 순서: `python gen_manual.py <pdf> .` → `book_tool extract` 로 layout_a → _a, layout_b → _b → `python merge_parts.py . <pdf>`
- merge_parts 보정: 다음 STEP 띠·필수예제 머리(barriers.json) 위에서 아래 끝 자름(7), 위 STEP 띠 아래로 윗변(38),
  확인체크 왼쪽 = 번호 x−3 (190), 연한 테두리 상자 아래 끝까지 늘림(23)
- 기하에서 바꾼 것: 쪽 범위 10~224, A 단 오른쪽 끝을 구분 점선 바로 앞(홀 390 / 짝 384)까지 넓힘
  (그림 오른쪽 끝·축 이름이 잘리던 것). 점선 맨 위(y 99~111)의 '생각해 봅시다' 아이콘에 걸친 38개는 예전 폭(385.5/379.8)으로.
