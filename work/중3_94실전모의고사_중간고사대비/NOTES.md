# 중3_94실전모의고사_중간고사대비

- 원본: `work\_src\중3\94 실전모의고사 중간고사대비 중3.PDF` (10쪽, 595x842pt, **스캔본** `source: ocr`)
- 내용: 어느 문제집 뒤쪽의 '중간고사 대비 실전 모의고사' 1~4회 (책 108~119쪽을 스캔한 것). 정답 없음.
- 문제 수: **79개** = 객관식·단답 63 + 서술형 16 (묶음·이어지는 문제 없음)
- 단원 4개: 모의고사 1회 / 2회 / 3회 / 4회
- 확신도: **중** (자르기는 정확하나 원본 스캔에 **쪽이 빠져 있음**)

## ⚠ 원본 누락
- 1회: 책 109쪽(09~16번) 이 PDF 에 없음 → 1회는 01~08, 17~20, 서술형 1~4 만 (16개)
- 3회: 책 115쪽(08~16번 추정) 이 없음 → 3회는 01~07, 17~20, 서술형 1~4 만 (15개)
- 2회·4회는 온전 (20 + 서술형 4 = 24개)

## 레이아웃 (두 번 뽑아 `merge.py` 로 합침)
- `layout_main.json`: 2단, 번호 `01`~`20` (12pt, `label_min_h 11.2` 로 보기 ①②(10pt 이하) 거름). 모든 쪽.
  오른쪽 단 x 는 570 까지 (쪽 오른쪽 끝 '실전 모의고사' 색 탭을 물지 않게). 흐린 마지막 줄 때문에 `bot_pad 12`.
- `layout_seosul.json`: 서술형 1~4 (오른쪽 단, 2·5·7·10쪽). 'OCR 이 `서술형 1` 의 숫자를 따로 못 읽어서 **16개 모두 `manual_labels`**
  (위치는 `ocrtext` 줄 위치). merge 때 label 을 `서술형1`~`서술형4`, column `R` 로 바꿈 (num 은 1~4).
- 실행: `python filter_extract.py <pdf> layout_main.json --out run_main` / `... layout_seosul.json --out run_seosul` → `python merge.py`

## 검수
