## ⚠ 레이아웃: 쪽마다 좌우 밀림이 제각각 → layout 여러 개
- 2단(라이트쎈 공통 모양)이지만 스캔 때문에 **쪽마다 가로 위치가 다름** (왼쪽 번호 x 23~56, 홀짝 규칙 없음).
  한 layout(columns/columns_even)으로는 단 경계가 옆 단을 물거나 번호를 놓침.
- 그래서 먼저 모든 쪽을 OCR 해서 쪽별 번호 x(밀림 c)를 재고, 6pt 단위로 묶어 `layouts/layout_shift<c>.json` 7개
  (각 파일의 `pages` = 그 밀림의 쪽 목록)로 따로 extract 한 뒤 쪽 순서로 합쳤다. 쪽↔밀림 대응은 `layout.json` 의 `page_shift`.
  - 단 x: 왼쪽 [c-12, c+252] / 오른쪽 [c+257, c+526], label_x: [c-6, c+9] / [c+257, c+276]
  - 공통 설정은 `layout.json`(참고용 통합본) / `layouts/base_settings.json`. 합치는 스크립트: `extract_by_shift.py`(참고용).
- 오른쪽 옆 단원 탭(색띠)이 일부 쪽 오른쪽 단 끝에 걸려 모아보기 오른쪽에 탭 조각이 조금 보이는 문제가 있음 (내용 지장 없음).
- `label_regex`: `^(?!0118|1105|1106|1109|1110|1112|1114)(0\d{3}|1[01]\d{2})[0'9]?$`
  - 번호 뒤 뱃지(난이도 동그라미)를 붙여 '01150', "0407'" 로 읽는 경우가 많아 끝 한 글자 [0'9] 허용
  - 보기·그림 숫자를 0118, 1105~1114 로 잘못 읽어 앞 문제를 잘라 먹던 것 → 제외하고 진짜 번호는 manual_labels 로
