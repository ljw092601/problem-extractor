# EBS 올림포스 공통수학1 (22개정)

- 원본: `고1/ebs/[22개정][EBS 올림포스] 공통수학1 본문.pdf` (로컬 사본 `work\_src\고1\ebs\...`), 174쪽
- 스캔본 → `"source": "ocr"`. **모든 쪽 rotation=180** (추출·모아보기·앱은 똑바로 나옴, 좌표는 똑바로 선 쪽 기준)
- 결과: **문제 310개** (problems.json 항목 311개 = 묶음 1개의 이어진 조각 1개 포함), 번호 1~313 빠짐 없음
- 단원: 13개 (8개 중단원 + 대단원 종합문제 4개 + 수행평가), `units.json`

## 방식 — 문제 코드로 번호 잡기
- 이 책은 **모든 학생용 문제 오른쪽 위에 `▶ 25445-NNNN` 코드**가 있고 NNNN 이 책 전체에서 1~313 으로 이어짐.
  풀이 붙은 예제(유형 상자)·서술형 연습장 왼쪽의 풀이 예시·정답 쪽에는 코드가 없음.
- 그래서 쪽 전체 OCR 에서 코드를 찾아 **번호 = 코드 NNNN**, y = 코드 윗끝 − 11 로 `manual_labels` 를 만들었다
  (자동 번호 인식은 끔: `label_regex` `^Z(\d)$`, `groups: false`, `rescue: false`, `drop_outliers: false`).
  OCR 로 313개 전부 찾음 (빠짐·중복 없음).
- 쪽 배치가 세 가지라 레이아웃 3개로 나눠 추출 후 합침:
  - `layout.json` — 2단 쪽 (유형 확인, 서술형 연습장, 대단원 종합문제, 수행평가). 홀수 쪽이 31pt 오른쪽으로 밀림 → `columns` / `columns_even`
  - `layout_basic.json` — 1단 '기본 유형 익히기' (유제만; 풀이 붙은 예제는 코드가 없어서 자동으로 빠짐)
  - `layout_hard.json` — 1단 '내신+수능 고난도 문항'
- 합칠 때 후처리(스크래치 스크립트, 결과만 problems.json 에 반영):
  - 유제 바로 밑에 다음 '유형 N' 제목·예제 상자가 30pt 안에 붙어 딸려 오던 것 → 단 왼쪽 여백에서 첫 내용 줄 위에서 자름 (56쪽 138, 57쪽 140, 85쪽 244)
  - 2단 쪽에서 문제 아래 갈색 '유형 N' 제목 숫자가 보이면 그 위에서 자르는 검사도 돌림 (이 책은 해당 없음)
  - **109쪽 수행평가 [1~4] 묶음** (공통 지시문 + 1~4, 두 단에 걸침) → 묶음 1개 (num 310, num_end 313, 왼쪽 단) + 오른쪽 단 조각 `continued: true`
