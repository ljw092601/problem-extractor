# 고3_미래엔_미적분

- 원본: `고3/미래엔 미적분.pdf` (로컬 사본 `work\_src\고3\...`), 194쪽, 612x792pt
- 종류: **스캔본** (`source: ocr`). 교과서가 아니라 **자습서(교과서 + 모든 문제 밑에 풀이·답 인쇄)** 형태.
- 결과: **281문제** — 본문 `문제 N` 106 + 중단원 마무리 107(13+14+10+18+18+18+16) + 대단원 평가 68(24+22+22) (묶음 0, continued 0)
- 확신도: **중상** (번호 빠짐 없음 확인, 풀이 잘라내기는 전체 모아보기로 눈 검수)

## 핵심: 풀이 잘라내기
모든 문제(본문 문제·마무리·평가) 바로 아래에 풀이가 붙어 있음 → 문제 영역만 남기고 풀이를 잘라냄 (`merge.py`).
- 아래끝 = min(extract 아래끝, 첫 `풀이` 뱃지(연한 주황 테두리) 윗끝, 서술형의 `문제 이해`/`해결 과정`/`답 구하기` 머리글 윗끝(OCR))
  + 풀이 첫 줄의 큰 분수가 뱃지 위로 솟은 부분은 빈 줄까지 올려서 뺌. 쪽 꼬리말(쪽 번호·단원명)도 뺌.
- 뱃지 238개, 서술형 머리글 22개로 자름. 못 찾은 21개는 단·쪽 맨 끝 문제(풀이가 다음 단/쪽에 있음)라 그대로 맞음.
- 흑백 인쇄라 뱃지 색이 안 잡힌 2개 + 풀이 첫 줄이 붙은 1개는 수동 아래끝 (`MANUAL_BOTTOM`: 61쪽 6, 141쪽 8, 71쪽 13).
- 다시 만들 때: layout_A/B 를 각각 `extract --no-sheets` → `python work\고3_미래엔_미적분\merge.py <A폴더> <B폴더> work\고3_미래엔_미적분\problems.json`

## 구역별 설정 (두 layout → merge.py 로 한 problems.json, 순서 = 쪽 → 단 → y)
| 파일 | 구역 | 번호 | 쪽(PDF) |
|---|---|---|---|
| layout_A.json | 본문 `문제 N` (1단, 왼쪽 여백 Hint 제외 x 138/148~531/568) | 한국어 OCR 로 '문제'+숫자 찾아 106개 전부 manual_labels | 4–18, 24–35, 47–69, 73–91, 97–122, 135–157, 164–180 |
| layout_B.json | 중단원 마무리·대단원 평가 (2단, `01` 큰 번호) | 번호 띠만 300dpi OCR(I→1, O→0 보정) + 눈 확인, 175개 전부 manual_labels | 19–23, 36–46, 70–72, 92–96, 123–134, 158–163, 181–194 |

- 두 layout 모두 `label_regex` 는 아무것도 안 맞게 두고 manual_labels 만 씀 (OCR 이 `10`,`11` 을 `IO`,`II` 로 읽어 빠지는 문제 회피).
- 본문 번호는 소단원(01, 02 …)마다 1부터 다시 시작.

## 남은 문제점 (사소함)
- 2단 구역 오른쪽 끝에 가운데 점선 구분선 일부가 딸려 옴(문제 내용은 온전).
- 본문 문제 왼쪽에 '탐구'/Hint 뱃지 조각, 문제 오른쪽 끝에 삽화가 같이 들어가는 경우 있음 (예: 154쪽 3, 174쪽 1–2).
- 일부 문제 아래끝에 풀이 첫 줄 윗부분(분수 가로줄 등) 몇 pt 조각이 남을 수 있음.
- 서술형은 '서·술·형' 표시 포함. 16쪽 등 문제 안 표(표 채우기)는 그대로.
