# EBS 올림포스 공통수학2 (22개정)

- 원본: `고1/ebs/[22개정][EBS 올림포스] 공통수학2 본문.pdf` (로컬 사본 `work\_src\고1\ebs\...`), 176쪽
- 스캔본 → `"source": "ocr"`. **모든 쪽 rotation=180** (추출·모아보기·앱은 똑바로 나옴, 좌표는 똑바로 선 쪽 기준)
- 결과: **문제 315개**, 번호 1~315 빠짐 없음 (묶음·이어진 조각 없음)
- 단원: 11개 (7개 중단원 + 대단원 종합문제 3개 + 수행평가), `units.json`

## 방식 — 문제 코드로 번호 잡기 (공통수학1 과 같은 방식)
- 모든 학생용 문제 오른쪽 위에 `▶ 25446-NNNN` 코드 (1~315). 풀이 붙은 예제·서술형 풀이 예시·정답 쪽에는 없음.
- 쪽 전체 OCR 로 코드를 찾아 **번호 = NNNN**, y = 코드 윗끝 − 11 로 `manual_labels` (자동 번호 인식 끔).
  315개 전부 찾음 (5쪽 광고의 오인식 1개는 쪽 범위 밖이라 버림).
- 레이아웃 3개로 나눠 추출 후 합침:
  - `layout.json` — 2단 쪽 (유형 확인, 서술형 연습장, 대단원 종합문제, 수행평가). 홀수 쪽 31pt 밀림 → `columns_even`
  - `layout_basic.json` — 1단 '기본 유형 익히기' (유제)
  - `layout_hard.json` — 1단 '내신+수능 고난도 문항'
- 합칠 때 후처리(결과만 problems.json 에 반영):
  - 유제 밑에 붙은 다음 '유형 N' 제목·예제 상자 잘라냄 (11쪽 5, 27쪽 50, 70쪽 195, 80쪽 221, 81쪽 223)
  - 2단 쪽 문제 밑에 딸려 온 갈색 '유형 N' 제목 잘라냄 (43쪽 104, 55쪽 140)
  - 유제 위로 앞 예제 풀이 조각이 비치던 것 위쪽 조정 (81쪽 224, 83쪽 227)
