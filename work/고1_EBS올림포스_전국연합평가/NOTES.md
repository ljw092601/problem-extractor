- 원본: `고1/ebs/2026 EBS 올림포스 전국연합평가 고1 문제.pdf` (로컬 사본 `work/_src/...`)
- 스캔본(OCR), 152쪽, 595x842pt. 정답·해설은 이 PDF에 없음(문제 전용).
- 문제 수: **761** (확인문제 + 내신+학평 유형 연습 + 1등급 도전, 11개 단원)

## 구성
단원마다 `개념 짚어보기`(개념 정리, 번호 문제 없음) → `개념 확인 문제`(01~) → `유형 연습`(01~, 기출 코드 26455-xxxx)
→ `1등급 도전`(01~). 번호가 부분마다 01부터 다시 시작 → `drop_outliers: false`.
기출 모음이지만 회차별이 아니라 **주제 단원별** 편집이라 units 는 목차의 11개 단원(대단원 7개로 묶음)으로 잡음.

## Point 상자 잘라내기 (후처리)
각 유형의 첫 문제 아래에 `Point` 팁 상자가 붙어 있고 문제와 간격이 좁아 gap_stop 으로는 못 끊음.
도구(core)는 고치지 않고 `postprocess/` 의 스크립트로 extract 결과를 후처리함:
1. `trim_point.py <pdf> <extract결과 problems.json> <tmp.json>` — 문제 영역 왼쪽 띠를 OCR 해 'Point' 글자 위 6pt 에서 자름 (200/300/150dpi 차례로)
2. `trim_pill.py <pdf> <tmp.json> problems.json` — OCR 이 놓친 것은 짙은 청회색 'Point' 알약 모양을 픽셀로 찾아 자름
→ 127곳 잘림 = 목차의 유형 수 합계(15+17+12+8+11+9+12+11+10+9+13=127)와 일치.
**재추출하면 이 두 단계를 다시 돌려야 함** (그냥 extract 결과를 쓰면 Point 상자가 딸려 옴).
