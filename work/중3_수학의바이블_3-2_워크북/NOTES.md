# 중3_수학의바이블_3-2_워크북

- 원본: `work\_src\중3\바이블\2021 수학의바이블 중등 3-2 워크북.pdf` (40쪽, 608x844pt, **스캔본** `source: ocr`)
- 문제 수: **168개** = 배운대로 복습하기 96 (묶음 3개 포함) + 서술형 훈련하기 72. 이어지는 문제 없음.
- 단원 10개 (두 파트 × 중단원 5)
- 확신도: **상** (번호 위치를 글자색으로 직접 찾아 전부 수동 지정 — 빠짐 없음 확인)

## 레이아웃 (두 번 뽑아 `merge.py` 로 합침)
- 뺀 쪽: 1 (파트 표지), 15 (파트 표지), 40 (메모)
- `layout_A.json` — 배운대로 복습하기 2-14쪽 (2단, 홀짝 밀림)
  - 번호 `01` 이 **회색 '0' + 주황 '1'** 이라 OCR 이 거의 못 읽음(0, 1, 3 따위로 읽음).
    → 주황 글자 덩어리를 번호 칸에서 찾아(스크래치 스크립트) 쪽마다 위에서부터 차례로 번호를 매겨 **99개 전부 `manual_labels`** 로 넣음,
    `label_regex` 는 아무것도 안 맞게(`^(NONE)$`), `rescue: false`.
  - 번호: 대부분 쪽마다 01~08. 8·9쪽(원주각)은 01~14, 10·11쪽은 01~14 로 이어짐.
  - 묶음 `manual_groups`: 3쪽 [07~08], 14쪽 [01~02]·[03~04] (`group_gap_stop 130`)
- `layout_B.json` — 서술형 훈련하기 16-39쪽 (2단, 홀짝 밀림). 한 쪽에 문제 2~3개, 각 문제 = 번호 상자 + 아래 STEP A~D 풀이 칸.
  - **문제 상자만** 자름 (`gap_stop 20` → STEP 풀이 칸 앞에서 끊김). 표가 딸린 문제(20쪽 13~15 등)도 표까지 들어옴.
  - 번호 색 거르기(`label_filter: color`) + 못 읽은 4개 `manual_labels`: 26쪽 1, 27쪽 5, 32쪽 1, 34쪽 7
- 실행: `python filter_extract.py <pdf> layout_A.json --out run_A` / `... layout_B.json --out run_B` → `python merge.py`

## 검수
- 모아보기 A 8장 중 4장, B 6장 중 3장 + 묶음·수동 번호 전부 직접 확인. 잘림·침범 없음.

## 남은 문제점
- 서술형 상자 아래 테두리 선이 살짝 빠질 수 있음(내용은 온전). STEP 풀이 칸(학생이 쓰는 곳)은 넣지 않음.
