## 방식 — 문제 코드로 번호 잡기 (EBS 올림포스와 같은 방식)
- 모든 학생용 문제 오른쪽 위에 `▶ 9050-NNNN` 코드, NNNN 이 책 전체에서 1~511 로 이어짐.
  문항 번호(01, 02 …)는 단원·모의고사마다 새로 시작하므로 **번호 = 코드 NNNN** 으로 잡음.
- '필수 유형'(기출 예제 + 출제 의도 + 풀이)에는 코드가 없어서 자동으로 빠짐 (풀이가 오른쪽 단 위로 넘어가는 경우도 번호가 없으므로 안 잘림).
- PDF 글자 정보에서 코드 위치를 찾고, 같은 줄 왼쪽의 큰 번호(01 등) 윗끝을 y 로 `manual_labels` 511개 생성
  (자동 번호 인식은 끔: `label_regex` `^Z(\d)$`, `groups: false`, `rescue: false`, `drop_outliers: false`).
- 2단. 가운데 구분선 짝수 쪽 x=313, 홀수 쪽 x=325 (홀수 쪽 11pt 오른쪽 밀림) → `columns` / `columns_even`. 홀수 쪽 오른쪽 끝 단원 탭(x≈615)은 안 물림.
- 후처리(스크래치 스크립트, 결과만 problems.json 에 반영): 자른 아래 경계에 걸친 글자 블록·도형(조건 상자 (가)(나) 의 연한 테두리, 표 밑줄, 분수 보기 등)이 있으면
  그 끝 +3pt 까지 아래 경계를 늘림 (다음 문제 번호 위에서 멈춤). 264개가 대부분 1~2pt, 조건 상자 몇 개는 5~14pt 늘어남.
- 문제 아래로 유형 제목 띠·필수 유형 상자가 딸려 오는 경우 글자 검사로 확인 → 없음.
