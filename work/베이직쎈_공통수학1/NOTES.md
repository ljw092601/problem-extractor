## ⚠ 이 책은 도구 기본 방식으로 안 됨 → 번호를 전부 수동 목록으로 넣음
- 번호가 **2자리이고 단원(개념/유형 묶음)마다 01부터 다시 시작**, 색 글씨(주황=개념 드릴, 초록=기본&핵심 유형, 파랑=실전)라 OCR 가
  보기 번호·수식 숫자와 구분을 못 함. 묶음 문제에 `[a~b]` 머리글도 없고 **초록 말풍선 아이콘 + 지시문**으로 시작함.
- 그래서 스크래치 스크립트로
  1) 단 왼쪽 번호 자리의 **색 덩어리(주황/초록/파랑)** 와 **말풍선 아이콘**을 찾고,
  2) OCR 숫자로 번호를 붙이고 (못 읽은 것은 앞뒤 순서로 채움),
  3) 아이콘 ~ 다음 초록/파랑 번호 전까지의 주황 번호들을 묶음으로
  만든 뒤, 결과를 layout 의 `manual_labels` / `manual_groups` 로 넣었다.
  자동 인식은 끔: `label_regex` = `^Z(\d)$`, `group_regex` = `^Z(\d)Z(\d)$` (아무것도 안 맞는 모양), `drop_outliers: false`.
- **PDF 1~24쪽은 180° 회전된 쪽** (page.rotation=180) 이라 홀짝 좌우 밀림이 뒤바뀜 → 레이아웃 파일 2개:
  - `layout_p8-24.json` (8~24쪽, 홀수 쪽 단 x [10,284][287,552], 짝수 [48,321][325,590])
  - `layout.json` (25~192쪽, 반대)
  - `problems.json` = 두 결과를 합친 것 (report.txt 도 두 개를 이어 붙임)
- 쪽 126, 188 은 흑백 스캔 → 색 대신 OCR 숫자 위치/어두운 덩어리로 처리
- 묶음 소문제 사이 여백이 커서(빈칸 풀이 공간) `group_gap_stop` 320 (범위는 다음 번호/아이콘에서 끊김)
- 수동 보정: 단원 표지(51쪽)·개념 쪽 머리띠(173, 174쪽)·'신기한 수' 상자 등에서 잘못 잡힌 것 제거, 68쪽 08번 추가, 156쪽 번호 수정
