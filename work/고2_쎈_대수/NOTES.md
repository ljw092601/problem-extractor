- `label_regex` `^(?!0114|0118)((?:0\d\d|1[01]\d|12[0-2])\d)(?![\d\-—.,}\)])` — 번호 0000~1229 만(본문 '1349','1391' 오인식 배제),
  뒤에 `}` `)` 붙은 것(‘1005}’, ‘017}’) 배제. 0114·0118 은 본문 숫자 오인식(19쪽 ½ → 0114, 124쪽 → 0118) 때문에 빼고 진짜는 manual 로.
- `label_min_h` 8.4: 보기 속 작은 숫자(1000, 1020 등 높이 7.7~8.2) 배제. 진짜 번호는 8.6~10.6.
- body [52, 800], top_pad 16(대표문제·서술형 도장), **bot_pad 12** (조건·보기 상자 아랫선이 옅어 6 이면 잘림), gap_stop 45.
- 홀짝 쪽 밀림이 거의 없어 columns 하나: 왼쪽 [28, 294], 오른쪽 [301, 562] (홀수 쪽 단원 색띠는 x≈570~).

## 추출 뒤 수작업 (재현: extract → fix_bottoms → add_cont)
1. `fix_bottoms.py` + `fix_spec.json`: 뒷면 비침(흐린 잉크) 때문에 영역이 다음 번호 바로 위까지 늘어나
   다음 '유형' 제목 띠 등이 딸려 온 13문제의 아래 끝을 진한 잉크 기준으로 다시 잡음
   (12쪽 0052, 17쪽 0092, 142쪽 0981, 143쪽 0985, 144쪽 0996, 146쪽 1010, 147쪽 1014, 148쪽 1024, 150쪽 1036, 158쪽 1098, 160쪽 1113, 168쪽 1162, 171쪽 1181) — 모아보기로 확인.
2. `continued.json` (+ `work\중2_쎈_2-1\add_cont.py`): 25쪽 묶음 [0141~0144] 가 왼쪽 단 아래에서 오른쪽 단 위(0143·0144)로
   넘어감 → 오른쪽 단 [301, 52, 562, 145] 를 continued 조각으로 추가.
```
python book_tool.py extract <pdf> work\고2_쎈_대수\layout.json --out D --no-sheets
cd work\고2_쎈_대수
python fix_bottoms.py <pdf> D\problems.json tmp1.json fix_spec.json
python ..\중2_쎈_2-1\add_cont.py tmp1.json problems.json continued.json
```
- `scan_bottoms.py` 는 검수 보조(읽기 전용): 진한 잉크 기준 끝과 bbox 끝 차이가 큰 문제 목록.
  나머지 차이는 빈 여백(뒷면 비침)뿐이고, 아래 끝에 진한 잉크가 있는 6개는 모두 문제 내용(보기·그림)임을 확인.
