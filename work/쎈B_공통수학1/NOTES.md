- 파란/주황 번호(`01`, `02` …)는 Windows OCR 이 자주 놓침(색 번호 + 옆 난이도 표시 `•◎•` 가 붙어 읽힘). 2자리 regex 로는 빠진 번호·가짜 번호가 수십 곳.

  - 번호 확인: 대부분 OCR 2자리 번호와 일치, 불일치/누락 구간은 render 로 직접 보고 확인(예: 90쪽 11번 수동 추가, 17·43쪽 등 단원 첫 쪽 01~09).
