# 고3_개념원리_미적분

- 원본: `고3/개념원리 미적분.pdf` (로컬 사본 `work\_src\고3\개념원리 미적분.pdf`)
- 텍스트 PDF (source: text), 312쪽, 533x729pt, PDF 목차 없음. 쪽 번호 = 교재 쪽 번호.
- 최종 항목 수: **603개** (묶음 0, 이어진 조각 0)
  - 개념원리 익히기 + 확인체크: 1~309 (한 번호 체계, 빠짐·중복 없음)
  - 연습문제(STEP1·2) + 실력UP: 1~294 (한 번호 체계, 빠짐·중복 없음)
- 확신도: **상** (번호를 글꼴·크기로 PDF 글자에서 직접 골랐고, 두 번호 체계 모두 1부터 끝까지 빠짐없이 한 번씩)

## 무엇을 넣고 뺐나
- 넣음: 개념원리 익히기, 필수예제 아래 **확인체크**, 연습문제 STEP1·STEP2, 실력UP (특강 107쪽 확인체크 102 포함)
- 뺌: **필수예제**(바로 아래 풀이가 붙어 있음), 개념원리 이해(설명), KEY Point, 오른쪽 여백 '생각해 봅시다!' 도움말
- 이 교재엔 '유제'가 없음 (확인체크가 그 역할)

## 레이아웃 (두 번 추출해서 합침)
`python gen_manual.py <pdf> <slug폴더>` → `layout_a.json`, `layout_b.json`, `barriers.json`
→ `python book_tool.py extract <pdf> layout_a.json --out _a --no-sheets` (b 도 같게)
→ `python merge_parts.py <slug폴더> <pdf>` → problems.json, report.txt

| 레이아웃 | 번호 글자 | 내용 | 자르는 x (홀/짝 쪽) | 항목 |
|---|---|---|---|---|
| layout_a.json | UniversLTStd-BoldCn 15.6 초록, x 59.5/53.9 | 익히기·연습문제·실력UP | 55–385.5 / 49–379.8 (오른쪽 여백 도움말·아이콘 뺌) | 350 |
| layout_b.json | UniversLTStd-BoldCn 14.0 초록, x 107.7/102 | 확인체크 | 번호x-3 ~ 486 (왼쪽 '확인체크' 뱃지 뺌) | 253 |

- 필수예제 번호(Helvetica-Bold 14.2)는 크기가 확인체크(14.0)와 거의 같아 text_size 로 못 가름 → 번호를 글꼴·크기로 골라 `manual_labels` 로 넣음 (label_regex 는 안 맞는 값, drop_outliers false, groups false).
- merge_parts.py 후처리:
  - 같은 쪽 아래 'STEP 2' 띠·필수예제 머리가 있으면 그 위(-8pt)에서 자름 (11곳)
  - 번호 바로 위 STEP 띠를 물면 윗끝을 띠 아래로 내림 (47곳)
  - 연한 회색 테두리 상자(보기·빈칸 채우기 상자)는 밝기 기준으로 내용이 아니라서 아래 테두리가 잘림 → 영역 안에서 시작한 상자 그림의 아래 끝까지 늘림 (35곳, 다음 문제 윗끝을 넘지 않게)
  - 쪽이 바뀌며 번호가 우연히 같은 서로 다른 문제(91쪽 확인체크 87 → 92쪽 연습문제 87)에 `num_end = num`. core.books.merge_continued 읽기 전용 확인 603 → 603.
- report 의 '빠진 번호'·'중복 번호(104쪽 103)'는 두 번호 체계가 섞여 나와서 생긴 것 (실제로 빠진 번호 없음).

## 단원 (units.json, 9개)
차례(6–8쪽) 기준 대단원 Ⅰ~Ⅲ(group) / 중단원 1. 2. …(title), 시작 = 각 중단원 표지 쪽.

## 남은 문제점
- 이어지는 문제 없음(각 쪽 첫 번호 위에는 STEP 띠·머리말·기출 표시만).
- 일부 문제 옆 QR 코드(동영상 강의, 예: 36쪽 34, 66쪽 69)는 번호 바로 아래에 있어 같이 잘림 (문제 내용은 온전).
- 확인체크 항목은 아래 답 쓰는 빈칸까지 들어가 조금 길 수 있음.
