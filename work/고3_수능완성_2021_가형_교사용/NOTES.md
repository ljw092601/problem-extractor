## 방식 — 문제 코드로 번호 잡기 (2020 가형과 같은 방식)
- 학생용 문제마다 오른쪽 위 `▶ 20050-NNNN` 코드, NNNN 이 책 전체 1~524 → **번호 = NNNN**.
  단원·모의고사마다 새로 시작하는 01, 02 … 는 쓰지 않음.
- '필수 유형'(기출 예제 + 출제 의도 + 풀이)에는 코드가 없어서 자동으로 빠짐. 풀이가 오른쪽 단 위로 넘어간 경우도
  첫 코드 문제 번호 위부터 자르므로 포함 안 됨 (글자 검사로 확인: 자른 영역 안에 '유형/출제/풀이/필수' 없음).
- 88번은 코드가 `7051-0088` 로 잘못 인쇄됨(37쪽 왼쪽 아래) → 코드 모양을 `\d{4,5}-\d{4}` 로 잡아 포함.
- 2쪽(교재 활용 안내)의 예시 코드 `20050-0001` 은 제외 (3쪽부터 찾음).
- 같은 줄 왼쪽 큰 번호(18pt) 윗끝을 y 로 `manual_labels` 524개 생성 (자동 번호 인식 끔: `label_regex` `^Z(\d)$`, `groups`/`rescue`/`drop_outliers` false).
- 2단. 짝수/홀수 쪽 11pt 밀림 → `columns`(홀수) / `columns_even`(짝수). 홀수 쪽 오른쪽 단원 탭 안 물림.
- 후처리(스크래치 스크립트, 결과만 problems.json 에 반영): 자른 아래 경계에 걸친 글자·도형이 있으면 그 끝 +3pt 까지 늘림
