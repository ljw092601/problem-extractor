## 쪽마다 좌우 밀림이 다름 → `shift_extract.py` 사용 (중요)
- 이 스캔은 쪽마다 단 위치가 달라짐(번호 x 가 왼쪽 단 27~65pt, 홀짝 규칙도 일정하지 않음, 일부 쪽은 살짝 기울어짐). `columns_even` 하나로는 옆 단을 물거나 잘림.
- 도구 코드를 고치지 않고, 스크래치 스크립트 `shift_extract.py`(이 폴더에 사본)가 실행 중에만 `core.extract.columns_for` 를 바꿔
  **쪽별 dx 만큼 단 좌표(columns 의 x·label_x)를 옮겨** 추출함. 그 밖의 과정(OCR·묶음·자르기·보고서)은 도구 그대로.
  - layout.json 의 `columns` 는 기준(dx=0, 번호 x 가 왼쪽 61·오른쪽 324 인 쪽) 좌표, `shift_ref: [61, 324]` (도구는 이 키를 무시).
  - 쪽별 dx 는 OCR 번호 x 로 측정한 값 → `page_dx.json` (번호 없는 쪽은 가까운 쪽 값).
- 재현: `python shift_extract.py "<pdf>" layout.json <out> --dx page_dx.json` → out/problems.json, report.txt, sheets
- **`book_tool.py extract` 로 그냥 돌리면 다른(틀린) 좌표가 나옴** — problems.json 을 그대로 쓸 것.

## 설정 요점
- `label_regex`: `^(0[0-4]\d{2})(?![\d\-—.,])` — 이 권 번호 범위(0000~0499)만. 20쪽 √1200·'10≤n' 을 1200·1092 로 읽어 0104·0110 이 잘리던 문제 해결.
- body [48, 798], top_pad 16, gap_stop 45. 단 x: 왼쪽 [46, 310], 오른쪽 [312, 576] (+dx).
