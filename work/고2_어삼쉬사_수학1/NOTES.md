# 고2 어삼쉬사 수학Ⅰ (학생용 본문)

- 원본: `고2/어삼쉬사/［어삼쉬사＿수학Ⅰ］ 학생용 본문.pdf` (대괄호·밑줄은 전각 ［ ］ ＿), 182쪽, 635x850pt
- 텍스트 PDF → `"source": "text"`
- 문제 수: **374개** = 핵심 문제 001~240 (SET 01~24) + [부록] 짝기출 001~134. 빠진 번호·중복 없음, 묶음 문제 0, 이어진 조각(continued) 0
- 단원 6개 (`units.json`): group "핵심 문제" / "[부록] 짝기출" × 대단원 Ⅰ 지수함수와 로그함수, Ⅱ 삼각함수, Ⅲ 수열.
  핵심 문제는 SET 마다 유형이 대단원 안에서 섞여 있어(중단원 순서가 아님) 중단원으로 나눌 수 없음 → 대단원(SET 8개 묶음) 단위.
- 확신도: **상**

## 쌍둥이
- 같은 폴더 `[어삼쉬사_수학Ⅰ] 학생용 본문_unlocked.pdf` (반각) 와 비교: 182쪽 전부 **쪽 크기·회전·글자(get_text) 동일, 30dpi 렌더 결과도 182쪽 모두 동일**
  → **쌍둥이: 쪽 구성 동일** (원본만 AES-256 암호화 표시, 내용 같음). 같은 좌표로 함께 등록 가능.

## 레이아웃
- 2단, 홀/짝 쪽 좌우 밀림 → `columns_even`. 홀수 쪽 오른쪽 옆 탭(x≥580) 안 물게 오른단 x 끝 578.
- 번호 '001' 이 글자 조각 '00' + '1' (또는 '0' + '11') 로 쪼개져 있음 → `label_regex` `^0*([1-9]\d{0,2})$` 로
  0 이 아닌 뒷조각만 번호로 잡음 ('00'·'0' 조각은 안 맞음). 크기 22pt (`text_size` [21,23]), SET 표시(25pt, y≈54)는 body 밖.
- `body` [100, 772]: 위 SET 띠·홀수 쪽 머리선, 아래 '이투스북' 로고·쪽번호·저작권 문구 제외.
- 번호가 핵심 문제 240 → 짝기출 1 로 다시 시작 → `drop_outliers: false`.
