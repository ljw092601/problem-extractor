## 방법 (고1 베이직쎈 공통수학1 과 같은 방식)
- 2자리 번호가 개념/유형마다 01부터 다시 시작하고 색 글씨(주황=개념 드릴, 초록=기본&핵심 유형, 파랑=학교 시험 기출·서술형),
  묶음은 `[a~b]` 머리글 없이 **올리브색 ▶ 아이콘 + 지시문**으로 시작 → 도구 자동 인식 불가.
- `tools/` 의 스크립트로
  1) `blabels.py`: 단 왼쪽 번호 자리의 색 덩어리 + OCR 숫자 수집 (`base1.json` 의 단 좌표 사용)
  2) `bb2.py`: 색으로 번호(O/G/B)·아이콘(I) 분류, OCR+순서로 번호 매김, 아이콘 ~ 다음 초록/파랑 번호/아이콘 전까지의 주황 번호를 묶음으로.
     - 번호 바로 위 '빈출' 도장 등은 제거, 옆으로 나란한 소문제(01 02 / 03 04)는 범위 끝을 다음 번호-1 로 늘림
     - **단/쪽을 넘어간 묶음**: 다음 단이 아이콘 없이 주황 번호로 시작하면 이어진 조각으로 처리 (앞 묶음 범위를 끝까지 늘림).
       예외(독립 문제): 9쪽 오른쪽 23·24, 141쪽 오른쪽 07·08 (`b1extra.json` 의 indep)
  3) `genlay.py` → `layout.json` (`manual_labels` 1232개 / `manual_groups` 140개, 자동 인식은 끔: `label_regex` `^Z(\d)$`, `group_regex` `^Z(\d)Z(\d)$`, `drop_outliers: false`)
  4) `book_tool.py extract` → `post_cont.py` 로 이어진 조각 20개에 `continued: true`, 번호·범위는 앞 묶음과 같게 (`b1_conts.json`)
- 단 x: 홀수 쪽 [52,318][327,590], 짝수 쪽 [44,310][316,582] (가운데 구분선 홀 321 / 짝 312.5), body [45,798], top_pad 16, group_gap_stop 320
