## 문제 구성 / 번호
- 번호는 교재 전체 연속 4자리 `0001`~`0926` → `label_regex` `^(0\d{3})(?!\d)` (0으로 시작만: '2020' 기출연도·'7421' 같은 OCR 잡음 차단).
- 넣은 것: 확인유제·변형문제·발전문제 (개념 설명 바로 뒤, 번호가 x≈100~120), 단원종합문제 BASIC/NORMAL/TOUGH (큰 번호, x≈45~75). 서술형 포함.
- 뺀 것: `마플개념익힘 NN` 예제(풀이·MAPL CORE 가 바로 붙어 있음, 4자리 번호 없음 → 자동 제외), 개념 설명, 마플특강·마플보충 해설, 쪽 아래 `정답` 띠.
- 이 책은 **해설편이 PDF 안에 없음** (432쪽 끝까지 본문). 각 쪽 아래 `정답` 띠만 있어 `body` 아랫값(758)으로 잘라냄.
- 묶음 문제([a~b] 머리글): 이 책에는 없음 (묶음 0개 — 정상).
- 1단 배치. 짝수 쪽이 오른쪽으로 ~15pt 밀려 `columns_even` 따로.
