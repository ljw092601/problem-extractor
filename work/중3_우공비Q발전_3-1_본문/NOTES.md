## 레이아웃 (layout.json)
- 번호 regex `^(\d{2})(?:[-_—–][12lI|])?$` (OCR 이 `01-1` 을 `01_1`, `02-I`, `06—1` 로 읽음), `label_min_h 11.5` (보기 번호 거르기)
- 단: 홀수 쪽 L [30,311] / R [306,572], 짝수 쪽 L [15,300] / R [305,566]. 쌍둥이 연결 점선은 R 단 왼쪽에 조금 보일 수 있음
- `gap_stop 28`: 60 이면 다음 유형 제목 띠(주황 띠)가 앞 문제 아래에 딸려 오고, 20 이면 문제 아래 식 상자가 잘림
- `ocr_dpi [150,200,300,400]`: 기본값으로는 번호를 많이 놓쳐서 늘림
- layout_top.json: 1단, 홀수 x [30,449] / 짝수 [12,436] (Tip 점선 x≈452 / 440 을 물지 않게)
