## 남은 문제점
- (고침) 필수 문제·STEP1 의 왼쪽 옆날개는 뺌 — 아래 참고.
- 단원 다지기의 보기 상자 아래 테두리가 조금 잘리는 곳이 있음(내용은 온전).
- 연습해 보자의 '풀이 과정' 빈칸은 빠짐(문제 본문은 온전). 서술형 완성하기 유제는 풀이 칸까지 넣음.
- 읽을거리 Q 문제를 넣은 것은 판단(번호 없는 기출 문제). 필요 없으면 reading 을 빼고 다시 합치면 됨.

## 왼쪽 옆날개 빼기 (검수 반영)
- 필수 문제·STEP1 항목의 bbox 왼쪽(x0)을 **문제 번호 바로 왼쪽(번호 글자 x - 1.5pt)**으로 옮겨 '필수 문제' 머리 상자·도움말 상자·그림(옆날개)을 뺌.
  오른쪽 본문·그림은 그대로(표본 10·11·59·108쪽 등 직접 확인). 번호 배지의 비스듬한 왼쪽 끝은 조금 잘림(숫자는 온전).
  옆날개 글자 끝·세로 테두리가 1~4pt 남는 곳이 몇 군데 있음(예: 11p #4, 59p #6).
- 방법: 레이아웃 단 x0 도 번호 쪽으로 좁힘(layout_concept_base.json 147/135, layout_step1.json 146/135: 홀/짝 쪽) +
  `gen_manual.py` 가 필수·STEP1 번호 x 를 `label_x.json` 에 적고, `merge_parts.py` 가 합칠 때 각 항목 x0 = max(단 x0, 번호 x - pad) 로 옮김.

  `python merge_parts.py <slug폴더> prep concept yuje step1 review essay reading` ("x0 fixed 235" 출력).
