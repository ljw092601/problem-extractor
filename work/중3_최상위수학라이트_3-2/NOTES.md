- 원본: `work\_src\중3\천재\최상위수학라이트3-2.pdf` (111쪽, 517x720pt, **스캔본** `source: ocr`). 인쇄용 재단선·꼬리말(파일명·날짜)이 있는 조판 PDF.
- 문제 수: **442개** = 주제별 실력다지기 360 + 단원 종합 문제 82. 묶음 0개, 이어지는 문제 없음.
- 단원 10개 (중단원 7 + 대단원별 단원 종합 문제 3). 단원마다 번호가 1 부터 끝까지 이어지며 **빠진 번호 없음** (units 결과의 문제 수 = 마지막 번호).
- 확신도: **상**

## 레이아웃 (두 번 뽑아 `merge.py` 로 합침)
- `layout_A.json` — 주제별 실력다지기 (1단): 7-21, 24-35, 43-58, 60-66, 68-76, 84-94, 96-105쪽.
  문제 칸 x 60~352 (오른쪽 옆의 **도움말 칸(x 355~)은 뺌** — 풀이 힌트라서). 번호 `01` 큰 글씨 → `label_min_h 12`.
- `layout_B.json` — 단원 종합 문제 (2단): 36-39, 77-81, 106-110쪽.
- column: A 는 1단이라 도구가 "0" 으로 적는 것을 merge 때 "L" 로 바꿈.
- 뺀 쪽: 1-4 (목차·표지), 5-6·22-23·41-42·59·67·83·95 (개념 정리), 40·82 (대단원 표지), 111 (삼각비의 표).
- 수동 번호: `10` 을 OCR 이 거의 못 읽음(굵은 좁은 글꼴) → 번호 칸의 굵은 글자 덩어리로 위치를 찾아 `manual_labels`:
  A: 9쪽 10, 25쪽 10, 44쪽 10, 61쪽 10, 62쪽 11, 69쪽 10, 86쪽 10, 98쪽 10 / B: 37쪽 10·11, 78쪽 10·11, 107쪽 10
- 실행: `python filter_extract.py <pdf> layout_A.json --out run_A` / `... layout_B.json --out run_B` → `python merge.py`

## 검수
- 모아보기 A 30장 중 6장, B 7장 중 2장 + 수동 번호 문제 직접 확인. 잘림·침범·도움말 딸림 없음.

## 남은 문제점
- 오른쪽 도움말(힌트)은 넣지 않음 (필요하면 A 의 x 범위를 460 까지 넓히면 됨).
