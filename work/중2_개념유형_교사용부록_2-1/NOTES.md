## 수동 보정 (fix_bbox.py — 코드 수정 아님, core.extract 함수만 읽어 씀)
다시 뽑을 때: `python book_tool.py extract <pdf> layout.json --out D --no-sheets` → `python fix_bbox.py <pdf> D/problems.json <slug폴더>`
1. 기초 강화 문제(20~37쪽): 소문항 (1)(2)… 사이 여백이 커서 gap_stop 40 으로는 아래가 잘림 →
   아랫변을 '다음 번호 / 다음 유형 제목 띠 바로 위'까지 큰 여백(200)으로 다시 잡음(29문제). 윗변이 유형 띠를 물면 띠 아래로.
2. 단 맨 위에 번호 없이 이어지는 소문항 → `continued` 조각 3개: 29쪽 오른쪽(2번 (4)~(10)), 31쪽 오른쪽(1번 (8)~(14)), 34쪽 오른쪽(2번 (3)).
3. 32쪽 1번(새 유형)이 31쪽 오른쪽 조각(1번) 바로 뒤라 merge_continued 가 합쳐 버림 → `num_end=1` 로 막음.
- merge_continued(읽기 전용) 확인: 625 → 622 (continued 3개만 합쳐짐, 서로 다른 문제 합침 없음).
